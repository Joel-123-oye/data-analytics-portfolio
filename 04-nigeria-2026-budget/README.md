# Nigeria 2026 Federal Budget Investigation

## Problem
Nigeria's 2026 Federal Budget dataset needed to be broken down into clear, public-facing insights on government spending priorities, including health.

## Approach
- Cleaned and analyzed the Federal Budget dataset in Excel
- Identified spending patterns across key sectors, including health
- Built visualizations translating the data for a non-technical audience
- Collaborated with a team to produce a data storytelling presentation for public accountability reporting

## Key Findings
- Highlighted which sectors received the largest share of the 2026 budget
- Made health-sector allocation trends visible in a way accessible to non-analysts

## Tools Used
Microsoft Excel, data visualization, data storytelling
