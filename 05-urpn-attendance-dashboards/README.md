# URPN Attendance & KPI Dashboards

## Problem
URPN needed a reliable way to track attendance and engagement for 100+ members across reporting cycles, with visibility for leadership review.

## Approach
- Track, document, and reconcile attendance records, ensuring accuracy and zero discrepancies
- Built interactive dashboards and visual reports in Power BI and Google Sheets
- Automated reporting workflows using Excel formulas, pivot tables, and charts

## Key Findings
- Reduced manual data entry time by over 30% through automation
- Gave leadership a clear, up-to-date view of participation trends and KPIs

## Tools Used
Power BI, Google Sheets, Microsoft Excel
