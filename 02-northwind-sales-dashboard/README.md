# Northwind Traders Sales Dashboard

## Problem
Northwind Traders needed a way for non-technical stakeholders to explore sales performance without relying on an analyst for every question.

## Approach
- Built a 3-page interactive Excel dashboard covering revenue trends, top products, countries, and employees
- Added dynamic filters so stakeholders could slice the data themselves

## Key Findings
- Revenue trend view made seasonal patterns visible at a glance
- Top-performing products and countries were easy to identify without pivoting manually
- Reduced back-and-forth between stakeholders and the analyst team for routine questions

## Tools Used
Microsoft Excel (pivot tables, charts, dynamic filters)
