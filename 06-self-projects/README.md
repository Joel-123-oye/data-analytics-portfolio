# Personal Projects (Self-Directed)

Two self-initiated Excel projects built outside of formal coursework, to practice pivot tables, dashboarding, and data storytelling independently.

## 1. UK Road Traffic Accident Analysis

### Problem
Wanted to practice building a fully interactive dashboard from a large, real-world dataset (UK road accident records).

### Approach
- Cleaned and structured UK road traffic accident data
- Built pivot tables analyzing casualties by month, road type, weather condition, road surface, and urban/rural split
- Built an interactive dashboard with slicers, allowing dynamic filtering by year and category

### Key Findings
- Urban areas recorded significantly more casualties than rural areas
- Dry road conditions accounted for the majority of casualties, ahead of wet conditions
- Daylight hours saw more casualties than darkness, reflecting higher traffic volume

### Tools Used
Microsoft Excel (PivotTables, PivotCharts, slicers)
