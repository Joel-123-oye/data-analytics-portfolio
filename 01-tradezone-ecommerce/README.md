# TradeZone E-Commerce Data Analysis

## Problem
TradeZone's relational database (hosted on Supabase/PostgreSQL) had data integrity issues across multiple tables, making it difficult to answer basic business questions about customers, sellers, and products.

## Approach
- Cleaned and structured the messy relational database, resolving integrity issues across tables
- Wrote 8 SQL queries covering customer retention, seller performance, and product trends
- Delivered a structured analyst memo to leadership with data-backed findings

## Key Findings
- Identified which customer segments were most likely to churn
- Flagged top and bottom-performing sellers by revenue and order volume
- Surfaced product trends leadership used to inform stocking decisions

## Tools Used
PostgreSQL, Supabase, SQL
