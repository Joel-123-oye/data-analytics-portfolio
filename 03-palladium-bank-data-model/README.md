# Palladium Bank Data Model

## Problem
18 months of raw bank transaction data was unstructured and produced inconsistent reporting whenever it was queried directly.

## Approach
- Designed a star schema, separating the data into fact and dimension tables
- Structured tables for customer, branch, and product-level analysis

## Key Findings
- Created a query-ready structure that eliminated the earlier reporting inconsistencies
- Reduced query complexity for common reporting needs by pre-modelling relationships

## Tools Used
PostgreSQL, SQL, data modelling / star schema design
